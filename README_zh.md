# 达芬奇密码 (DaVinci Code) 在线多人桌游

这是一个支持实时多人的“达芬奇密码”在线桌游系统，采用 **Next.js 14 App Router + Tailwind CSS + Framer Motion + PostgreSQL** 全栈技术开发。系统不仅支持本地开发运行，还完美适配 Serverless 部署与 Docker 容器化一键部署（包含宿主机持久化数据挂载与内置轻量 PostgreSQL 服务）。

## ✨ 系统核心功能与特色

* **🔑 强制用户注册与安全认证 (Bcrypt Authentication)**：
  * **登录门禁校验**：用户必须先完成账号注册/登录，方可创建房间或进入任何现有房间。系统在前端与后端 PostgreSQL 数据库双重校验用户合法身份。
  * **密码安全哈希**：采用标准的 `bcryptjs` 加盐哈希加密算法将用户密码安全保存于数据库中，绝不留存明文密码。
  * **会话持久化**：登录状态自动持久化保存于浏览器 `sessionStorage`，刷新或重新打开网页无需重复登录。

* **🃏 黑白双任意百搭牌 (`-` 牌) 完整规则**：
  * **26 张完整牌堆**：包含黑色 0-11（12 张）+ 白色 0-11（12 张），以及 **1 张黑色任意百搭牌 `-`** 和 **1 张白色任意百搭牌 `-`**。
  * **自由排位与特殊标记**：手牌中任意百搭牌呈现尊贵金黄色 `-` 标识及 `百搭` 气泡；猜牌决策弹窗内置包含 `- (任意百搭牌)` 的完整按键阵列。

* **🏆 个人战绩与全服胜率排行榜 (`/stats`)**：
  * 数据库在 `users` 表中永久保存每位玩家的对战数据（`total_games` 场次, `total_wins` 胜场, `total_losses` 负场），在 `match_history` 表中保存每局开赛时间与胜负明细。
  * `/stats` 战绩页面展示“个人历史对战明细”与“全服胜率排行榜”（榜首独享金色 🥇 尊贵外观），支持移动端自适应排版。

* **🎉 结算弹窗防自动跳转 & 全员手牌底牌公开**：
  * 游戏结束时自动显示胜利/对局完结弹窗，并**完全公开场上所有玩家的最终手牌数字与百搭牌**，供玩家复盘底牌。
  * 取消自动强制跳转，只有当玩家亲自点击 `[返回房间待命 (准备下一局)]` 按钮后，才会平滑切回房间等待大厅。

* **⏰ 30 秒倍数超时提醒机制**：
  * 轮到自己回合时触发独立计时器，当停留思考超过 30 秒、60 秒、90 秒... 时，自动弹窗与浮动 Toast 醒目提醒玩家做出选择。

* **🎨 现代化 Better-UI & 双主题切换**：
  * 基于 `better-ui` 设计工程规范，支持全局触觉式按压反馈 (`Scale on Press`)、同心圆角与双色（Light/Dark）主题自由切换。
  * 针对 iPhone / Android 移动端屏幕进行全方位适配，绝无文字重叠或竖排错位。

* **🐳 Docker 一键部署与数据持久化**：
  * 提供 `docker-build.sh`（一键打包部署）与 `cleanDBAndRestart.sh`（一键清空数据重置）Shell 脚本；
  * 挂载宿主机目录 `/root/davinci_pgdata:/var/lib/postgresql`，即使重新打包镜像或更新代码，用户账号与对战历史战绩数据**永久保存**。

## 🛠️ 整体技术栈

* **核心框架**：Next.js 14 (App Router)
* **前端视图与动效**：React 18, Tailwind CSS, Framer Motion, Lucide React
* **后端 API**：Next.js Route Handlers (RESTful 无状态 API)
* **密码加密**：Bcryptjs (加盐哈希算法)
* **数据库**：PostgreSQL (配合 `pg` 连接池与 JSONB 二进制大对象存储)
* **容器化**：Docker (内置 PostgreSQL 15 与自动化 Shell 部署脚本)

## 🚀 快速开始

本项目支持 **Docker 一键镜像启动** 或 **本地开发环境启动**。

### 方式一：Docker 一键 Shell 脚本部署（推荐，端口 60824 & 数据持久化保存于 `/root/davinci_pgdata`）

我们在 Docker 镜像中封装了 Next.js 运行环境与内置 PostgreSQL 数据库：

1. **一键运行部署脚本**：
   ```bash
   chmod +x docker-build.sh && ./docker-build.sh
   ```
2. **重置/清空数据库并重新部署脚本**（可选）：
   ```bash
   chmod +x cleanDBAndRestart.sh && ./cleanDBAndRestart.sh
   ```
3. **访问游戏**：
   打开浏览器访问 `http://<服务器IP>:60824` 即可开始游玩！

---

### 方式二：本地 Node.js 开发环境运行

需准备 [Node.js (22+)](https://nodejs.org) 和运行中的 [PostgreSQL (14+)](https://www.postgresql.org)。

#### 1. 安装项目依赖
```bash
npm install
```

#### 2. 配置环境变量
在根目录创建 `.env.local` 环境变量文件：
```env
DB_HOST=localhost
DB_PORT=5432
DB_USER=root
DB_PASSWORD=root
DB_NAME=davinci
```

#### 3. 运行数据库迁移脚本
初始化 `davinci` 数据库及所需的 `users` / `rooms` 表结构：
```bash
node scripts/setup-pg.js
```

#### 4. 启动开发服务器
```bash
npm run dev
```
启动后访问 `http://localhost:3000` 或 `http://localhost:60824`。

#### 5. 生产构建打包
```bash
npm run build
npm start
```

## 🎮 游戏规则与对局流程

1. **注册与登录账号**：
   * 首次进入必须在主页注册或登录账号，未登录用户无法创建或进入任何房间。
2. **创建或加入房间**：
   * 已登录用户可创建房间（支持自定义房间号与密码）或直接点击“可用房间列表”中的房间加入。
3. **等待与开赛**：
   * 房间内满 2-4 人时，房主界面会醒目提示并展示“开赛”按钮，点击即可发起对局。
4. **回合行动逻辑**：
   * **摸牌**：轮到行动的玩家首先从黑色或白色牌堆中摸一张牌，普通牌按数字升序（黑左白右）排列，任意百搭牌（`-` 牌）显示在右侧。
   * **猜牌**：点击任意对手的一张暗牌，选择猜测数字 `0`-`11` 或 `- (任意百搭牌)`。
     - **猜对**：对手该牌被公开。可以选择继续猜测别的隐藏牌，或点击 Pass 结束回合。
     - **猜错**：作为惩罚，自己本轮新摸的牌将被强制公开，且本轮回合结束。
   * **认输与出局**：手牌全部公开的玩家宣告出局；玩家亦可主动选择“认输”。生存到最后的唯一玩家获得胜利。
5. **对局结算与复盘**：
   * 胜利/完结弹窗中全量公开所有玩家的最终手牌底牌，确认无误后点击 `[返回房间待命 (准备下一局)]` 回到等待大厅。
